This is an example post that shows the frontmatter every devlog entry needs.
Set `draft: false` (or remove the line) to publish a post.

- `lang`: `en` or `tr`. English posts go in `src/content/devlog/en/`, Turkish posts in `src/content/devlog/tr/`.
- `translationKey`: the same value on an English post and its Turkish translation links them with hreflang.
- `heroImage`: optional, a path relative to this file (for example `../../../assets/slots-and-skulls/screenshots/fight_view.jpg`), with `heroImageAlt` describing it.
